# Quiz-Game

A command-line multiple-choice quiz game built with Python. Created for the Daryl Tech & Educational Network (DTEN) Introduction to Python Internship, Task 1.

About the Project

Pick a category, answer five multiple-choice questions, and get your score. The game tracks your best score in each category while the program is running.

Features
Loop-based main menu that repeats until you choose Exit
3 categories with 5 questions each: Python Basics, General Knowledge, Science
Questions and answer options are shuffled every game
Instant feedback after every answer (and the right answer if you were wrong)
Final score with percentage and an encouraging message
High score for each category
Graceful handling of invalid input (empty name, letters instead of numbers, answers other than A-D, out-of-range menu choices)
Code organized into functions and commented step by step

How to Run
Download or clone this repository.
Open a terminal in the project folder.

Run:
Mac / Linux
python3 quiz_game.py

Windows
python quiz_game.py
